Global Student Migration Analysis

Project Overview

This project analyzes global student migration patterns using Python. It explores study destinations, origin countries, scholarship distribution, enrollment reasons, and employment outcomes.

Objectives

- Identify the top 10 student destination countries.
- Analyze enrollment reasons for students choosing the UAE.
- Identify the top 10 origin countries.
- Explore scholarship distribution by origin country.
- Compare placement status with academic scores (CGPA).
- Analyze average starting salaries by placement country.
- Compare starting salaries across fields of study.
- Explore relationships between origin and destination countries.

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning

- Checked missing values.
- Handled missing values using suitable replacements.
- Checked duplicate records.
- Reviewed data types and numerical columns.

Analysis and Visualization

The project uses bar charts, count plots, pie charts, and heatmaps to identify patterns and compare student migration and employment outcomes.

Key Findings

- Identified the most common study destinations.
- Compared scholarship distribution across origin countries.
- Examined placement outcomes and CGPA.
- Compared starting salaries by country and field of study.
