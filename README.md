GLOBAL STUDENT MIGRATION ANALYSIS

Project Overview

This project analyzes global student migration patterns using Python. It explores destination countries, origin countries, scholarship distribution, enrollment reasons, and employment outcomes.

Objectives

- Identify the top 10 student destination countries.
- Analyze enrollment reasons for students choosing the UAE.
- Identify the top 10 origin countries.
- Explore scholarship distribution by origin country.
- Compare placement status with academic scores (CGPA).
- Analyze average starting salaries by placement country.
- Compare starting salaries across fields of study.
- Explore relationships between origin and destination countries.

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
